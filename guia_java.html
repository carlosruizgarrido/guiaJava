public static void invertir(int fin, int[] t) {
    for (int i=0; i<fin; i++) {
        int aux = t[i];
        t[i] = t[fin-1];
        t[fin-1] = aux;

    }

public class Lista {
    public Integer[] tabla;
    public int contador;       // nº de elementos reales

    public Lista(int tamaño) {
        tabla    = new Integer[tamaño];
        contador = 0;
    }

    public void insertarNumeroFinal(int n) {
        if (contador == tabla.length) redimensionar();
        tabla[contador] = n;
        contador++;
    }

    public void eliminarElemento(int indice) {
        for (int i=indice; i<contador-1; i++)
            tabla[i] = tabla[i+1];
        contador--;
    }

    protected void redimensionar() {
        tabla = Arrays.copyOf(tabla, tabla.length + 1);
    }

    @Override
    public String toString() {
        String r = "[";
        for (int i=0; i<contador; i++) {
            r += tabla[i] + (i < contador-1 ? ", " : "");
        }
        return r + "]";
    }
}

Copiar fichero byte a byte — FileInputStream / FileOutputStream
try {
    FileInputStream  original = new FileInputStream("origen.jpg");
    FileOutputStream copia    = new FileOutputStream("copia.jpg");

    // Opción A: byte a byte (lento)
    while (original.available() > 0) {
        byte b = (byte) original.read();
        copia.write(b);
    }

    // Opción B: con buffer (rápido, usar siempre)
    byte[] buffer = new byte[4096];          // 4 KB de buffer
    int bytesLeidos;
    while (original.available() > 0) {
        bytesLeidos = original.read(buffer);   // lee hasta 4096 bytes
        copia.write(buffer, 0, bytesLeidos);  // escribe solo los leídos
    }

    copia.close();
    original.close();
} catch (IOException e) {
    System.err.println("Error: " + e.getMessage());
}
Usar buffer de 4096 bytes es ~4000× más rápido que leer byte a byte. Usar siempre en copia de ficheros grandes.

Fichero de texto vs fichero binario — diferencias
Texto (.txt)Legible con cualquier editor. Usa FileReader/BufferedReader. Pierde precisión en doubles.
Binario (.dat .bin)No legible directamente. Usa ObjectOutputStream/InputStream. Guarda el valor exacto.
¿Cuándo texto?Configuración, logs, CSV, ficheros que el usuario editará manualmente.
¿Cuándo binario?Objetos completos, arrays, datos numéricos con precisión exacta, mayor rendimiento.
